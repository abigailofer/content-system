# Words to avoid

Terms that should not appear in Evinced UX writing. Use this as a checklist during review.

---

| Word or phrase | Reason / alternative |
|----------------|----------------------|
| advancing | Vague — say what you're actually doing |
| agenda | Use only when referring to a meeting |
| and so forth | Vague — be specific |
| approximately | Use "about" |
| assist | Use "help" |
| click | Use "select" |
| collaborate | Use "working with" |
| combating | Use "working against" or "fighting" |
| commit or pledge | Be specific — either you're doing it or you're not |
| countering | Use "answering" or "responding" |
| current version / previous version | Use "latest version" / "older version" |
| deliver | Only for pizzas, mail, and physical services — not abstract concepts |
| deploy | Only for military or software contexts |
| dialogue | Use "speak to" or "talk to" |
| disincentivize / incentivize | Vague — say what you mean |
| dropdown | Use "drop-down menu" |
| empower | Vague — say what the user can actually do |
| enable / disable | Use "turn on" / "turn off" |
| execute | Use "run" or "do" |
| facilitate | Say specifically how you are helping |
| focusing | Vague — say what you're focused on |
| foster | Use only when referring to children |
| illegals / illegal aliens | Use "undocumented immigrants" |
| impact / impactful | Vague — describe the actual outcome |
| in order to | Use "to" |
| initiate | Use "start" |
| innovative | Describe the positive outcome instead |
| install widget | Use "add widget" |
| key | Use "important" or omit — unless it literally unlocks something |
| land | Use only when referring to aircraft |
| leverage | Use only in financial contexts |
| liaise | Use "work with" or "partner with" |
| modify | Use "change" |
| overarching | Vague — be specific |
| progress | Say what you're actually doing |
| promote | Use only for ad campaigns or marketing promotions |
| purchase | Use "buy" |
| reload | Use "refresh" or "restart" |
| robust | Vague — describe what makes it strong |
| see | Use "show all results" or "view all results" |
| shows | Use "indicates" |
| simple / simply | Use "straightforward", "uncomplicated", or "clear" — or omit |
| slimming down | Processes don't diet — say what's actually changing |
| sorry | Avoid over-apologizing |
| streamline | Vague — say what's actually being simplified |
| strengthening | Use only for physical structures |
| success / successful / successfully | Vague — describe the actual outcome |
| such as | Use "like" |
| tackling | Use only for contact sports |
| tap | Use "select" |
| thought leader | Reference the person's actual accomplishments |
| timezone | Use "time zone" |
| toggle | Name the specific control instead |
| touchpoint | Name the specific system component |
| transforming | Say what is actually changing |
| user testing | Use "user research" or "usability testing" |
| utilize | Use "use" |
| watch video | Use "play video" |
