# Words to use

Approved word choices for Evinced UX writing. When in doubt, use the word in the left column.

---

| Use this | Instead of |
|----------|------------|
| about | approximately |
| add widget | install widget |
| buy | purchase |
| change | modify |
| clear | simple / simply |
| contact Evinced Support (inline text) | contact us / get help |
| Contact Support (button label) | contact us / get help |
| do | execute |
| drop-down menu | dropdown |
| help | assist |
| indicate | show |
| latest version / older version | current version / previous version |
| like | such as |
| play video | watch video |
| refresh / restart | reload |
| run | execute |
| select | click / tap |
| show all results / view all results | see |
| start | initiate |
| straightforward / uncomplicated / clear | simple / simply |
| time zone | timezone |
| to | in order to |
| turn on / turn off | enable / disable |
| undocumented immigrants | illegals / illegal aliens |
| use | utilize |
| user research / usability testing | user testing |
| working against / fighting | combating |
| working with | collaborate / liaise |
