# Glossary

Product-specific terms used across Evinced UX writing skills.

---

## Element

An element is a unique part of the page's structure. It can be one HTML element or a group of nested elements with a single root.

If the same structure appears more than once, it becomes a Component.

**Exception:** If a single instance matches a known UI Pattern, it is treated as a Component instead of an Element.

---

## Component

A component is a part of the page that appears more than once. Components can either follow a known UI Pattern or be custom.

**Exception:** Even a single instance is a Component if it matches a known UI Pattern.

---

## UI design pattern

A UI design pattern is a familiar design pattern with specific traits used to identify common interface elements. It can be recognized through code analysis or visual detection.
