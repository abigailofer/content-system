# Rubric: Writing Onboarding Steps

---

## Pass if all are true
- [ ] If a CTA launches a modal, the modal title matches or closely reflects the CTA label
- [ ] Step headlines are ≤50 characters
- [ ] Step headlines use sentence case
- [ ] Step headlines have no trailing period
- [ ] Step headlines contain no exclamation points
- [ ] Step bodies are ≤150 characters
- [ ] Step bodies use sentence case and end with a period
- [ ] Action labels are ≤25 characters
- [ ] Action labels use title case
- [ ] Action labels have no trailing period
- [ ] Action labels use verb + noun, or single-word labels only where step context makes the outcome clear
- [ ] Total steps ≤7 (recommend 3-5)
- [ ] Step order follows logical progression
- [ ] First step sets expectations (what user will accomplish and how long it takes)
- [ ] Final step celebrates or confirms completion without exclamation points
- [ ] Required vs. optional onboarding is clear to user
- [ ] Progress indicator is present for multi-step flows
- [ ] Step copy focuses on the user as the actor, not the product
- [ ] Flow copy focuses on completing steps, not selling features
- [ ] Each step provides enough context without requiring memory of previous steps

---

## Fail if any are true
- [ ] Modal title contradicts or uses different action words than the CTA that launched it
- [ ] Character limits exceeded
- [ ] Headline uses title case or has a trailing period
- [ ] Headline contains an exclamation point
- [ ] Body text is missing a trailing period
- [ ] Action label uses sentence case or has a trailing period
- [ ] Step copy centers the product rather than the user ("We built this for you" vs "You can now...")
- [ ] Flow copy sells features inside the flow instead of focusing on completing steps
- [ ] CTA is a single generic word ("Continue", "Next") without sufficient step context to make the outcome clear
- [ ] Steps can be completed in different order but presented as linear
- [ ] No indication of total steps or progress
- [ ] Mandatory setup disguised as optional tour
- [ ] Final step doesn't provide clear next action
- [ ] Steps use jargon user hasn't learned yet
- [ ] More than 7 steps in a single flow
- [ ] Step relies on user remembering information from a previous step
