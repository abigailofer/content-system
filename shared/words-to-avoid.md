# Words to Avoid

Terms that should not appear in Evinced content. Use this as the canonical reference during review. Skills may add context-specific guidance, but must not duplicate this list.

---

| Word or phrase | Reason / alternative |
|----------------|----------------------|
| additionally | Too formal — use "also" or restructure the sentence |
| advancing | Vague — say what you're actually doing |
| agenda | Use only when referring to a meeting |
| and so forth | Vague — be specific |
| anomalous | Use "unusual" or "unexpected" |
| approximately | Use "about" |
| ascertain | Use "find out" or "check" |
| assist | Use "help" |
| bespoke | Too formal — use "custom" or "tailored" |
| click | Use "select" |
| collaborate | Use "work with" |
| combating | Use "working against" or "fighting" |
| commit or pledge | Be specific — either you're doing it or you're not |
| comprehensive | Vague — describe what it covers specifically |
| constitute | Use "form" or "make up" |
| countering | Use "answering" or "responding" |
| curate | Vague — say what you're selecting or organizing |
| current version / previous version | Use "latest version" / "older version" |
| cutting-edge | Vague — describe what's new or different |
| deliver | Only for pizzas, mail, and physical services — not abstract concepts |
| delve into | Use "look at", "explore", or "examine" |
| deploy | Only for military or software contexts |
| dialogue | Use "speak to" or "talk to" |
| disincentivize / incentivize | Vague — say what you mean |
| dropdown | Use "drop-down menu" |
| e.g. / i.e. | Use "for example" or "like" (e.g.) and "that is" (i.e.) |
| effortlessly | Vague — say what makes it easy, or omit |
| empower / empowering | Vague — say what the user can actually do |
| enable / disable | Use "turn on" / "turn off" |
| endeavor / endeavour | Use "try" |
| erroneous | Use "incorrect" or "wrong" |
| etc. | Use "and so on" or be specific |
| execute | Use "run" or "do" |
| facilitate | Say specifically how you are helping — use "help" or "allow" |
| focusing | Vague — say what you're focused on |
| foster | Use only when referring to children |
| furthermore | Use "also" or restructure the sentence |
| harness | Too formal — say what you're actually using |
| hence | Use "so" or "therefore" |
| holistic approach | Vague — describe the specific approach |
| illegals / illegal aliens | Use "undocumented immigrants" |
| impact / impactful | Vague — describe the actual outcome |
| in order to | Use "to" |
| in the realm of | Too formal — say what you mean directly |
| in today's fast-paced world | Cliché — omit or state the specific context |
| indeed | Filler — omit or restructure |
| initiate | Use "start" |
| innovative | Describe the positive outcome instead |
| install widget | Use "add widget" |
| it's important to understand that | Filler — omit and state the fact directly |
| it's worth noting that | Filler — omit and state the fact directly |
| key | Use "important" or omit — unless it literally unlocks something |
| land | Use only when referring to aircraft |
| leverage | Use only in financial contexts |
| liaise | Use "work with" or "partner with" |
| mitigate | Use "reduce" or "limit" |
| modify | Use "change" |
| moreover | Use "also" or restructure the sentence |
| myriad (of) | Use "many" or be specific |
| navigate (challenges) | Vague — say what you or the user actually does |
| necessitate | Use "require" |
| nonsensical | Use "makes no sense" or "confusing" |
| optimal / optimize | Vague — describe the specific improvement |
| overarching | Vague — be specific |
| paradigm shift | Cliché — describe the actual change |
| plethora (of) | Use "many" or be specific |
| progress | Say what you're actually doing |
| promote | Use only for ad campaigns or marketing promotions |
| purchase | Use "buy" |
| reload | Use "refresh" or "restart" |
| robust | Vague — describe what makes it strong. Acceptable when referring to WCAG. |
| seamless / seamlessly | Vague — describe what makes it smooth, or omit |
| see / open | Use "view", "check", or "refer to" depending on context |
| show / shows | Use "indicate" or "indicates" |
| simple / simply | Use "straightforward", "uncomplicated", or "clear" — or omit |
| slimming down | Processes don't diet — say what's actually changing |
| sorry | Avoid over-apologizing |
| streamline | Vague — say what's actually being simplified |
| strengthening | Use only for physical structures |
| success / successful / successfully | Vague — describe the actual outcome |
| such as | Use "like" |
| superfluous | Use "unnecessary" or "extra" |
| supersede | Use "replace" |
| synergy / synergistic | Vague — describe how things work together |
| tackling | Use only for contact sports |
| tap | Use "select" |
| thought leader | Reference the person's actual accomplishments |
| timezone | Use "time zone" |
| toggle | Name the specific control instead |
| touchpoint | Name the specific system component |
| transforming | Say what is actually changing |
| undoubtedly | Filler — omit or state the evidence |
| user testing | Use "user research" or "usability testing" |
| utilize | Use "use" |
| watch video | Use "play video" |
